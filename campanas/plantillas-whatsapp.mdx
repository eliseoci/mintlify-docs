title: Plantillas de WhatsApp
description: Creá y revisá los mensajes que Meta debe aprobar para tus envíos.
---
Una plantilla de WhatsApp es un mensaje con un formato aprobado por Meta. No es una plantilla de agente ni una estructura de embudo.

## Crear una plantilla

1. Entrá a **Plantillas de WhatsApp**.
2. Seleccioná **Crear plantilla**.
3. Completá el nombre, idioma, categoría y contenido solicitado.
4. Si usás variables, agregá valores de ejemplo.
5. Si agregás imagen, video o documento, cargá el ejemplo requerido.
6. Revisá y enviá la plantilla a Meta.

## Revisar el estado

Una plantilla puede estar lista para usar, en revisión, rechazada o pausada. Si Meta todavía no la aprobó, no la uses como si estuviera disponible.

Usá **Sincronizar** para actualizar la información cuando corresponda. Si fue rechazada, revisá el motivo y corregí el contenido.

## Usar una plantilla

Desde una plantilla disponible podés iniciar su uso en una campaña. Comprobá que el idioma, las variables y el canal correspondan al envío.

## Archivos de ejemplo y archivos del agente

El archivo de ejemplo se carga para revisar la plantilla. Si querés que el agente comparta un catálogo durante el chat, configurá también [Enviar imágenes y archivos](/agentes/enviar-archivos).
