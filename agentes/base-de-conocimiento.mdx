Usá **Fuentes** para aportar información sobre productos, precios, políticas y preguntas frecuentes. Necesitás permiso para editar el conocimiento de tu organización.

## Elegir una fuente

Según las opciones habilitadas, podés trabajar con archivos, textos, páginas web y preguntas y respuestas.

1. Abrí **Fuentes** y elegí el tipo de contenido.
2. Cargá el archivo o completá la información solicitada.
3. Guardá y esperá a que el contenido esté disponible.
4. Probá una pregunta concreta cuya respuesta esté en esa fuente.

## Preparar contenido útil

- Incluí información vigente y específica de tu negocio.
- Separá productos, condiciones y políticas con títulos claros.
- Evitá versiones contradictorias de precios o plazos.
- Actualizá o quitá contenido que ya no esté vigente.

## Comprobar una respuesta

Preguntá por un dato que sólo esté en la fuente. Si la respuesta no es correcta, revisá que el contenido se haya procesado y que las instrucciones permitan usarlo.

## Compartir el archivo con el cliente

Agregar un PDF como fuente no configura su envío al cliente. Para compartirlo, agregá una [herramienta de envío de archivos](/agentes/enviar-archivos).
